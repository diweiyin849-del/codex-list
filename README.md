# 拾序 · Todo List

一个简洁的个人待办清单，包含网页版和 Python 命令行版本。

## 网页版

直接用浏览器打开 `index.html`，无需安装依赖。

- 添加、完成和删除任务
- 筛选全部、待完成和已完成任务
- 清除已完成任务并查看完成进度
- 任务保存在当前浏览器的本地存储中

## 命令行版

安装 Python 3 后运行：

```bash
python todo.py
```

按终端提示管理任务。任务数据保存在 `todo_data.json` 中，该文件不会上传到 GitHub。

## 文件说明

- `index.html`：网页结构
- `style.css`：页面样式
- `app.js`：任务管理与本地存储
- `todo.py`：命令行待办清单
